Bug Showcase: split(" ") vs split()

A common bug in beginner Python code: calling text.split(" ") with an explicit space instead of text.split().

Requirement 9

Why the Bug Happens

When you call split(" ") with a literal space string, Python splits strictly on every individual space. If there are two spaces in a row, Python splits between them and creates an empty string "" as a fake word! Furthermore, it fails to strip leading spaces, trailing spaces, tabs (\t), or newlines (\n).

When you call split() without arguments, Python automatically groups any sequence of contiguous whitespace into a single delimiter and strips leading/trailing whitespace.

Setup & Secure API Configuration Guide

Instructions for running this project in Visual Studio Code and securely configuring AI API keys.

VS Code Ready

1. How to Open in Visual Studio Code

  1. Download or clone the project folder.
  2. Open VS Code and choose File > Open Folder... and select python_assistant_project.
  3. To run the web interface directly, install the Live Server extension in VS Code, right-click index.html, and select "Open with Live Server".
  4. To run tests in the terminal: python3 -m unittest test_string_analyzer.py.

2. Secure API Key Configuration (Never Hardcode!)

When connecting to Google Gemini AI API or any real Generative AI provider, never put API keys in client-side HTML/JS or hardcode them into git repositories.

A
Create a .env file: Add your key locally: GEMINI_API_KEY="your_api_key_here"
B
Add .env to .gitignore: Prevents accidentally committing secrets to GitHub.
C
Use server-side proxy (Python Flask / Express): The backend reads os.getenv("GEMINI_API_KEY") securely and the browser only talks to /api/ai/*.
